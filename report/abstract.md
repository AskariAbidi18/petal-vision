## Abstract

This project presents an unsupervised approach to analyzing flower images using classical Digital Image Processing techniques. A dataset of over 250 flower images captured around a college campus was processed without any prior labeling. The pipeline includes image standardization, preprocessing, segmentation, feature extraction, and clustering. Flower regions were segmented using the GrabCut algorithm, and visual features related to color, shape, and texture were extracted. The resulting feature vectors were standardized and clustered using K-Means clustering. Internal clustering metrics and visual inspection were used to evaluate the results. The study demonstrates that meaningful appearance-based groupings can be obtained using classical image processing methods, while also highlighting the challenges posed by natural variability in real-world image data.
