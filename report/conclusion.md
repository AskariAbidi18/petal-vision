## Conclusion

This project demonstrates the application of classical Digital Image Processing techniques for unsupervised analysis of natural flower images. Despite the absence of labeled data, the proposed pipeline was able to extract meaningful visual features and identify appearance-based groupings using K-Means clustering. The results reveal partial clustering driven primarily by color tone, brightness, and spatial characteristics, with noticeable overlap between clusters. This overlap reflects the inherent variability of natural images and the limitations of global handcrafted features. Overall, the project highlights both the strengths and challenges of unsupervised image analysis and emphasizes the continued relevance of classical image processing methods alongside modern learning-based approaches.
